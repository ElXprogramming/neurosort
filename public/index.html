System Architecture & Pipeline

Built with an unyielding commitment to data safety: files are never modified in-place, partial downloads are held back until size stabilizes, and every single move is committed to SQLite before execution.

1

Watchdog Daemon

Monitors filesystem events (on_created, on_moved) on intake directories with configurable debouncing.

2

Stabilization Check

Verifies non-zero file size across two checks spaced 2s apart to filter active browser downloads (.crdownload, .tmp).

3

Content Extractor

Pulls metadata & snippets: pymupdf for PDF text, piexif for camera/GPS, code AST, and MIME signatures.

4

Semantic Classifier

Ollama local LLM analyzes content to output structured JSON with taxonomy target and standardized naming. Fallback to keyword heuristics if offline.

5

Safe Atomic Move

Checks target collision (_v1), computes SHA-256, moves file, and writes transaction record to SQLite ledger.

CLI Commands & Quickstart

Everything in NeuroSort is controlled through an ergonomic Typer + Rich terminal interface.

1. Initialize Configuration neurosort init 
$ neurosort init
✔ Successfully created configuration at: ./config.yaml
✔ Destination root established at: ~/Documents/Organized

Scaffolds default configuration and taxonomy directories.

2. Dry-Run Preview Scan neurosort scan --dry-run 
$ neurosort scan ~/Downloads --dry-run
Original File        Target Folder      Conf.   Status
invoice_march.pdf    Finance/Invoices   0.95    PREVIEW
photo_beach.jpg      Media/Photos       0.90    PREVIEW

Previews proposed classifications without touching files on disk.

3. Background Watcher Daemon neurosort start 
$ neurosort start
⚡ Watcher active. Press Ctrl+C to stop.
Watching ~/Downloads (5.0s debounce)
Watching ~/Desktop/Inbox (5.0s debounce)

Continuously ingests, debounces, and sorts dropped files.

4. Instant Undo / Rollback neurosort undo 
$ neurosort undo --last 1
Tx ID   Restored Source Path       Result
#42     ~/Downloads/invoice.pdf    REVERTED
✔ Rollback completed (1 operation restored).

Instantly reverses file movements back to original locations.
